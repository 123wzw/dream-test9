# CSV 读取要求（FORMAT_SPEC）

本文是验收依据，列出的每一条都要满足。

## 1. 编码识别

读取时必须自动识别以下编码，不得要求调用方指定：

- UTF-8（带 BOM 与不带 BOM）
- UTF-16 LE / BE（带 BOM）
- GBK

识别失败时抛 `DecodeError`，不得返回乱码。

## 2. 字段解析

- 字段用英文逗号分隔。
- 双引号包裹的字段中，**逗号、换行、回车**都算字段内容，不视为分隔符。
- 字段内的双引号用两个双引号转义，例如 `"a""b"` 解析为 `a"b`。
- 行结束符支持 `\n`、`\r\n` 混用。
- 文件末尾没有换行时，最后一行同样要读出来。

## 3. 空值与 NULL

| 输入 | 结果 |
|---|---|
| 字段完全为空（`,,`） | `None` |
| 字段内容为 `NULL`（大小写不敏感） | `None` |
| 字段内容为 `""`（两个引号，无内容） | 空字符串 `""` |

## 4. 类型推断

对每个非空字段做推断：

| 形态 | 推断结果 |
|---|---|
| `123`、`-7` | `int` |
| `3.14`、`-0.5` | `float` |
| `2024-03-01` | `datetime.date` |
| `true` / `false`（大小写不敏感） | `bool` |
| 其他 | `str`（保持原样，不去空格） |

- 前导零的字符串（如 `007`、`0123`）必须保留为 `str`，不得转成整数。
- 科学计数法 `1e5` 视为 `str`。

## 5. 结构校验

- 每行列数必须与表头一致，不一致抛 `FormatError`，并在错误信息中带上行号。
- 输出为 `list[dict]`，键为表头字段名，顺序与文件一致。

## 6. 流式与资源

- 除 `read_csv` 外，还必须提供 `iter_csv(path)`，逐行产出 `dict`，**不得把整个文件读进内存**。
- 读取 100 MB 文件时，进程峰值内存增量不得超过 **128 MB**。
- 解析 100 万行、8 列的 UTF-8 文件，耗时不得超过 **8 秒**。

## 7. 错误恢复

- `read_csv` 默认严格模式：列数不齐抛 `FormatError`，错误信息必须带**行号**（从 1 开始，表头为第 1 行）。
- `read_csv(path, skip_bad=True)` 为容错模式：跳过坏行继续解析，返回 `(rows, stats)`，`stats` 含 `total`、`skipped`、`errors`（`errors` 为 `(行号, 原因)` 列表）。
- 容错模式不得因为单行错误而丢失后续所有行。

## 8. 验收方式

- 对 `data/` 下每个样例文件调用 `read_csv`，结果的行数、列名、取值、类型都要正确。
- 样例覆盖：UTF-8 BOM、UTF-16、GBK、引号内逗号、引号内换行、转义引号、CRLF 混用、无末尾换行、空字段、NULL、前导零、日期、布尔。
